📘 第一章：英语的"三套词汇"——先看懂单词从哪来

🎯 学完这章你能： - 用一句话回答"为什么 water、aqua、hydro 长得完全不一样，但意思都是'水'？" - 看到一个新单词，大致判断它是"日常词"还是"高级词"

1.1 英语其实是个"混血儿" 🧬

中文是一脉相承的，几千年下来基本是同一个系统。

但英语不是！今天你课本里看到的英语，其实是一千多年里，英国人不断吸收别的语言"拼"出来的。

它主要由 三套词汇 组成：

🟢 第一套：日耳曼词汇（本族词/日常词）

解释：这是英语"亲生"的词，最老、最日常、最口语。说英语的英国人，从一千多年前就在用这些词。

特点：短、好读、高频。

例子：water（水）、house（房子）、eat（吃）、see（看）、hear（听）、foot（脚）、man（人）、mother（妈妈）

你怎么认出它：一般又短又好念，像生活里随时能用上的词。

🟡 第二套：拉丁语词汇（书面词/高级词）

解释：一千年前，法国的诺曼人打到了英国，带来了大量法语（法语本质上是拉丁语的后代）。从那以后，英语就吸收了海量拉丁系的词。这些词通常拆成"词根+词缀"再用。

特点：更长、更书面、更正式，考试爱考。

例子： - aquatic（水生的）← aqua（水）+ tic（形容词后缀） - visible（可见的）← vis（看）+ ible（能…的） - audible（可听的）← aud（听）+ ible（能…的）

你怎么认出它：看起来"洋气"、字数多、常出现在文章和试卷里。

🔵 第三套：希腊语词汇（学术词）

解释：古希腊是欧洲学术的源头，所以理工、医学、心理学这些"专业领域"的词，绝大多数来自希腊语。

特点：学院派、专业、长得很"严肃"。

例子： - psychology（心理学）← psycho（精神）+ logy（学科） - telescope（望远镜）← tele（远）+ scope（看） - biology（生物学）← bio（生命）+ logy（学科） - hydrogen（氢）← hydro（水）+ gen（产生）

你怎么认出它：一看就是"学术词"，理化生课本里超多。

1.3 📖 词源故事：英语的三次"大混血"

第一波（5-11世纪）：盎格鲁人、撒克逊人从德国北部来到不列颠，带来了日耳曼语——英语的根基。这些词是最基础的日常词：life、death、eat、sleep...

第二波（1066年起）：诺曼底公爵威廉征服英格兰。法语成为统治阶级的语言，英语沦为平民口头语。结果出现了超有趣的"阶级双轨词汇"：

第三波（1500-1650年）：文艺复兴时期，英国学者从拉丁语和希腊语借了 10000+ 个新词。这些看起来吓人的长词，全是前缀+词根+后缀拼出来的。越长的词，结构越清晰，反而越好记！

6.1 加字母：为了好发音 ➕

直接拼起来读不顺，就中间加个字母让它顺一点。

  • pent(五) + gon(角) → 直接拼是 pentgon，读不顺 → 加个 a → pentagon(五角形)

  • swim + ing → 双写 m → swimming
  • begin + ing → 双写 n → beginning
  • run + ing → 双写 n → running

6.2 减字母：为了简洁顺口 ➖

几个字母挨在一起读起来累赘，就砍掉一个。

  • maintain + ance → maintenance（去掉了一个 ai）
  • describe + tion → description（be → p，又少了一个 e）
  • argue + ment → argument（去掉了 e）
  • true + ly → truly（去掉了 e）

🚨 8 个常见陷阱词详解

🚨 8 个常见陷阱词详解

📖 最重要的规律

当前缀 in- 遇到以下情况时 不表否定：

  1. in- 表示"进入/加强"：incense(激怒), inborn(天生的), inbound(到达的)
  2. in- 作为"使动"前缀：inflame(点燃), illuminate(照亮)

识破陷阱的方法： - ✅ 把推测的含义放到句子中检验是否通顺 - ✅ 如果词根推测的含义与上下文矛盾，优先信任上下文

📖 词源故事④：inflammable——美国消防部门的教训

inflammable 看起来像"不(in) + 可燃(flam) + able"，但实际上 in- 在这里是"进入/加强"的意思！所以 inflammable = 非常容易燃烧的 = flammable。

这个混淆曾经造成严重的安全事故——人们以为 inflammable 的东西是"不可燃的"，放松了防火警惕。为此，美国消防部门专门改用 flammable / non-flammable 作为安全标签，避免混淆。

💡 记住：inflammable = 易燃 🔥，non-flammable = 不可燃 ✅
